认证约定

用户系统使用单个 JWT 作为登录凭证。客户端在需要认证的接口中通过请求头传递 token。

请求头

Authorization: Bearer <token>

JWT Payload

字段说明
sub用户 ID
username用户名
jtiJWT 唯一 ID，用于退出登录后的服务端吊销
iat签发时间
exp过期时间
  • JWT 签名有效。
  • JWT 未过期。
  • jti 未被吊销。
  • 用户状态为 active。

通用错误码

错误码说明
INVALID_REQUEST请求参数不合法
UNAUTHORIZED未登录或 token 无效
USER_DISABLED用户已被禁用
INTERNAL_ERROR服务内部错误

业务模块专属错误码在对应业务接口文档中说明。
