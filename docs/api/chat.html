AI 聊天接口

聊天会话、历史消息和发送消息接口。通用规范见 API 接口总览。

返回文档预览 Markdown 原文
接口目录 会话列表 创建会话 更新会话 删除会话 历史消息 发送消息

业务错误码

错误码说明
CHAT_SESSION_NOT_FOUND聊天会话不存在或无权访问
CHAT_SESSION_ARCHIVED聊天会话已归档，不能继续发送消息
MESSAGE_TOO_LONG消息内容超过长度限制
AI_RESPONSE_FAILEDAI 回复生成失败

领域模型

chat_sessions

字段类型建议说明
idBIGINT UNSIGNED会话 ID
user_idBIGINT UNSIGNED所属用户 ID
titleVARCHAR(120)会话标题，可由首条消息生成
statusENUM('active', 'archived')会话状态
last_message_atDATETIME NULL最近一条消息时间
created_atDATETIME创建时间
updated_atDATETIME更新时间

chat_messages

字段类型建议说明
idBIGINT UNSIGNED消息 ID
session_idBIGINT UNSIGNED所属会话 ID
user_idBIGINT UNSIGNED所属用户 ID
roleENUM('user', 'assistant')消息角色
contentMEDIUMTEXT消息正文
statusENUM('completed', 'failed')消息状态
sequence_noINT UNSIGNED会话内递增序号
modelVARCHAR(64) NULLAI 回复使用的模型
prompt_tokensINT UNSIGNED NULL输入 token 数
completion_tokensINT UNSIGNED NULL输出 token 数
error_messageVARCHAR(500) NULLAI 回复失败原因
created_atDATETIME创建时间

GET/api/chat/sessions

查询当前用户的聊天会话列表，默认按 lastMessageAt 倒序排列。

查询参数

参数类型默认值说明
statusstringactiveactive、archived
pagenumber1页码
pageSizenumber20最大 50

成功响应

{ "data": { "items": [ChatSession], "page": 1, "pageSize": 20, "total": 1 }, "error": null }
POST/api/chat/sessions

创建一个空聊天会话。也可以直接通过发送首条消息自动创建会话。

请求体

字段类型必填说明
titlestring否会话标题

成功响应

{ "data": { "session": ChatSession }, "error": null }
PATCH/api/chat/sessions/:sessionId

更新当前用户的聊天会话。首版支持修改标题和归档状态。

请求体

字段类型必填说明
titlestring否新会话标题
statusstring否active、archived
DELETE/api/chat/sessions/:sessionId

删除当前用户的聊天会话，并同时删除该会话下的历史消息。只想隐藏会话时，应改用归档状态。

成功响应

{ "data": { "success": true }, "error": null }

错误响应

HTTP错误码说明
400INVALID_REQUEST请求参数不合法
401UNAUTHORIZED未登录或 token 无效
403USER_DISABLED用户已被禁用
404CHAT_SESSION_NOT_FOUND会话不存在或不属于当前用户
GET/api/chat/sessions/:sessionId/messages

查询当前用户指定会话的历史消息，默认按 sequenceNo 升序排列。

查询参数

参数类型默认值说明
afterSequenceNonumber无只查询该序号之后的消息
limitnumber50最大 100

成功响应

{ "data": { "session": ChatSession, "items": [ChatMessage], "hasMore": false }, "error": null }
POST/api/chat/messages

发送用户消息并通过 SSE 流式生成 AI 回复。sessionId 为空时服务端自动创建新会话。

请求体

字段类型必填说明
sessionIdstring否会话 ID
contentstring是用户消息内容，最大 4000 字符

SSE 响应头

HTTP/1.1 200 OK
Content-Type: text/event-stream; charset=utf-8
Cache-Control: no-cache
Connection: keep-alive

SSE 事件

事件名说明
session会话信息
user_message已保存的用户消息
assistant_deltaAI 回复增量文本
assistant_message已保存的完整 AI 回复消息
done本次回复结束
errorAI 回复生成失败

SSE 成功响应示例

event: session
data: {"id":"1","title":"帮我设计一个登录页面","status":"active"}

event: user_message
data: {"id":"1","sessionId":"1","role":"user","content":"帮我设计一个登录页面","status":"completed","sequenceNo":1}

event: assistant_delta
data: {"content":"可以，"}

event: assistant_delta
data: {"content":"先确认登录方式和目标用户。"}

event: assistant_message
data: {"id":"2","sessionId":"1","role":"assistant","content":"可以，先确认登录方式和目标用户。","status":"completed","sequenceNo":2}

event: done
data: {"success":true}

SSE 失败响应示例

event: error
data: {"code":"AI_RESPONSE_FAILED","message":"AI 回复生成失败","assistantMessage":{"id":"2","status":"failed","errorMessage":"AI response failed"}}
