# Docs

项目文档目录，用于记录接口说明和后续工程约定。

## 文档列表

- `API-DOC.md`：API 接口总览，记录基础信息、统一响应格式、认证约定、通用错误码和业务文档入口。
- `API-DOC.html`：API 接口总览静态预览页。
- `api-preview.html`：API 文档静态预览首页，可直接在浏览器中打开。
- `api/auth.md`：用户认证接口文档，包含注册、登录、恢复当前用户和退出登录。
- `api/auth.html`：用户认证接口静态预览页。
- `api/chat.md`：AI 聊天接口文档，包含聊天会话、历史消息和发送消息接口设计。
- `api/chat.html`：AI 聊天接口静态预览页。

## 维护约定

新增或修改 API Markdown 文档时，默认同步生成或更新对应的 HTML 预览页。
